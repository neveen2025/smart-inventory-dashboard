# Smart Inventory Dashboard

A responsive Smart Inventory Dashboard built using HTML, CSS, and JavaScript.
## 🔗 Live Demo

[View Live Demo](https://neveen2025.github.io/smart-inventory-dashboard/)

## 🚀 Features

- Add new products
- Delete products
- Search products
- Calculate total revenue dynamically
- Dynamic product management
- Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
  

## 🎯 Project Purpose

This project was created to practice JavaScript and DOM manipulation by building a practical inventory management dashboard.
